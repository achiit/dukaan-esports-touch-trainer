Esports Touch Trainer

Practise finger placement, tap speed, joystick control and fire-button drags. Every number comes from real touch events on this page. It does not connect to or control any game.

Round Selection

Landscape gives the most room. Each round stores its own data. Compare them on the results screen after finishing both.

How measurements work
  • Press duration: finger down to finger up on one button. Interval: finger down to the next finger down on the same button. Reaction time: cue shown to finger down, only when the reaction test is on. Drag duration: first movement to release.
  • Times use the browser's pointer event timestamps (same clock as performance.now()). They show when the browser received each touch, not how fast any game would respond. Screen touch sampling limits precision to a few milliseconds.
  • The reaction clock starts at the next screen frame after the cue is switched on. Display delay is not measured, so compare reaction times only within this app.
  • Distances are in CSS pixels, so the same drag on a different screen size gives a different number. Pausing or finishing discards a press that is still being held; joystick movement up to that moment is kept.
  • Layout, locks and rounds are saved in this browser only.
